# 哔哩偶遇 · 线下擦身通信概念原型

参考任天堂 3DS「すれちがい通信」(StreetPass) 的思路，为哔哩哔哩线下活动设计的一个概念功能原型：粉丝的客户端在 UP 主进入设定范围（最远 2km）时收到模糊提醒，只知道对方的粉丝量级，不知道具体是谁；一旦双方走到 3 米内当面确认，身份直接揭晓，粉丝还能收下 UP 主赠送的专属电子签名。

> 这是一个纯前端的静态 HTML 演示，**不是哔哩哔哩官方功能**，不涉及真实定位或蓝牙，页面中的 UP 主昵称、头像、视频数据均为虚构占位内容，仅用于说明交互构想。

## 核心机制

1. **远距离神秘信号**（500m / 1km / 2km 可选）— 只显示粉丝量级徽章，身份是否公开由 UP 主的「身份可见度」设置决定（仅量级 / 神秘签名 / 公开昵称）。
2. **3 米内当面确认**— 距离进入 3 米自动解锁真实身份，并生成一张带编号、带手写寄语的电子签名收藏卡。
3. **擦肩图鉴** — 无论远距离提醒还是当面签名，都会被记录进粉丝端的收藏列表。

## 隐私设计

功能的另一半重点是「双向」的隐私控制，UP 主端和粉丝端各自拥有对称的开关，任何一方都能收紧或放开：

- UP 主端：广播总开关、粉丝量级、身份可见度、可见范围、广播对象（所有人 / 仅关注 / 仅大会员）、定时广播、近距离解锁签名
- 粉丝端：擦肩提醒总开关、提醒范围、免打扰时段、仅接收已关注 UP 主、位置精度（模糊区间 / 精确定位）、打招呼时是否公开昵称

## 本地运行

两个文件都是零依赖的单文件 HTML，直接双击用浏览器打开即可，字体通过 Google Fonts CDN 加载（断网时会自动回退到系统字体，不影响功能）。

也可以用任意静态服务器预览，例如：

```bash
npx serve .
```

### 部署到 GitHub Pages（可选）

推送到 GitHub 后，在仓库 `Settings → Pages` 中选择对应分支和根目录，即可通过类似
`https://<你的用户名>.github.io/<仓库名>/` 的地址在线访问（`index.html` 会作为默认首页，即可交互原型）。
