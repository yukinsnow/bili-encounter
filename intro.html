线下活动最容易被浪费的，是那些擦肩而过却互不知情的瞬间——一位百万粉丝的 UP 主可能就站在你身后排队，你们谁都没发现。

任天堂在 3DS 上用「すれちがい通信」解决过类似问题：两台设备靠近时自动交换数据，不需要主动加好友，也不打断彼此的行程。哔哩偶遇把这个思路搬到线下活动里——用粉丝量级代替具体身份，先给一点"好奇心"，真正走近了再彻底揭晓。

HOW IT WORKS

一次偶遇，分三步揭晓

距离决定了粉丝能看到多少信息——越远越神秘，走到面前才彻底"确认"，而每一次确认都会被永久收藏。

01

远距离神秘信号

UP 主进入自定义范围（500m / 1km / 2km）后，粉丝端会收到一条模糊提醒——只显示粉丝量级徽章，具体是谁、显示到什么程度，全部由 UP 主的「身份可见度」设置决定。

最远可达 2000m
02

当面确认 · 解锁签名

真正走到 3 米以内，神秘感自动解除：昵称与头像直接揭晓，同时收到一张带编号、带手写寄语的专属电子签名，作为这次偶遇的凭证。

≤ 3m 自动触发
03

图鉴永久珍藏

无论是远距离的神秘信号还是当面确认的签名，都会被记录进粉丝的「擦肩图鉴」，成为这场活动独一无二的参与记录，也是下次见面时的谈资。

随时可回看
FEATURES

专为线下活动设计的六个细节

不是简单的"附近的人"，而是把粉丝好奇心、UP 主安全感、活动现场氛围都考虑进去的一整套机制。

分级好奇心

10万 / 50万 / 100万 / 1000万 四档粉丝量级各有专属配色徽章，配合「仅量级 · 神秘签名 · 公开昵称」三档身份可见度，UP 主可以决定这次露多少脸。

10万+50万+100万+1000万+

电子签名收藏

3 米内确认后自动生成一张带编号的手写风格签名卡，是这次线下活动独有的数字纪念品。

现场信号台

工作人员可用一块控制面板现场触发不同量级的擦肩信号，配合舞台环节或摊位打卡使用。

广播对象定向

UP 主可以把信号只开放给「所有人 / 仅关注我的人 / 仅大会员」，为专属粉丝群体设计限定环节。

双向隐私控制

UP 主端和粉丝端各自拥有完整的隐私设置——广播范围、免打扰时段、位置精度、是否在打招呼时暴露昵称，两边的选择会互相影响最终结果，而不是单方面的开关。

PRIVACY BY DESIGN

UP 主端 × 粉丝端，隐私各自说了算

「擦身而过」的前提是双方都感到安全——所以每一项设置都成对出现，任何一方都能随时收紧或放开。

设置项UP 主端粉丝端
总开关 开启附近广播 — 关闭后不会出现在任何人的雷达上 擦肩提醒 — 关闭后仍静默记录，只是不弹窗
距离范围 可见范围 — 500m / 1km / 2km，超出即完全侦测不到 提醒范围 — 500m / 1km / 2km，超出不弹窗但仍会记录
身份程度 身份可见度 — 仅量级 / 神秘签名 / 公开昵称 位置精度 — 模糊距离区间（推荐）/ 精确定位
对象定向 广播对象 — 所有人 / 仅关注我的人 / 仅大会员 仅接收已关注 UP 主 — 陌生 UP 主不打扰你
时间控制 定时广播 — 仅活动时段自动开启 免打扰模式 — 指定时段内不弹出任何提醒
近距离确认 近距离解锁签名 — 3 米内自动公开身份并赠送签名 打招呼时公开昵称 — 决定 UP 主能否看到你是谁
